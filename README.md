# Selected Contributions

- [`pybandee`](https://github.com/MothNik/pybandee/tree/refactor-penta-numba) is a `numba`-implementation of the [`pentapy`](https://github.com/GeoStat-Framework/pentapy)-backend for solving pentadiagonal linear systems. I also implemented the multi-threading in Cython for `pentapy` (see [this pending PR](https://github.com/GeoStat-Framework/pentapy/pull/27)), but I needed a `numba`-compatible solutions, so I implemented my own.
- A cubic spline interpolator for [`PyLops`](https://github.com/PyLops/pylops). Its implementation can be used within `pytorch` and allows for backpropagation.
